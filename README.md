# 루미 모자이크

중학교 1학년 상대도수의 비율과 자원 배분을 연결한 12라운드 퍼즐. 꾸러미 선택 → 창 선택으로 플레이합니다. 되돌리기는 손길을 사용하고 재시작은 제한 없습니다.

`npm test`, `npm run build`, `npm start`로 각각 검사·정적 빌드·로컬 실행합니다. Vercel Import 시 별도 서버·API 키 없이 배포할 수 있습니다. 브라우저에 진행과 생각 노트를 저장하며 서버 로그인은 없습니다. 새 수치의 표·히스토그램·비교 과제와 설명 기록은 `assessment/`에서 별도로 다룹니다. 기록은 인쇄할 수 있고 JSON 원문을 학생에게 노출하지 않습니다.

Azul의 묶음 선택 원리를 참고하되 게임 규칙·수학 변형·그림은 새로 제작했습니다. 출처와 범위는 내부 메타데이터에 기록합니다. 원문 PDF·추출문은 포함하지 않습니다.
